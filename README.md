Model Context Protocol servers and agent workflows that connect AI to the tools you actually run — CMS, CRM, sheets, internal APIs — so the model can do the work instead of just describing it.

`MCP` `AI Agents` `Tool Use` `REST APIs`

`Keyword Research` `On-Page SEO` `Programmatic SEO` `Content Strategy`

`A/B Testing` `CRO` `UI Experimentation` `Analytics`

### 🎯 Lead Generation Automation

`Python` `Playwright` `Proxycurl` `SQLite`

### 🌐 Web & E-Commerce Engineering
